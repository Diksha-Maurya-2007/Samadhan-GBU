# Samadhan-GBU
Samadhan: GBU Grievance Portal prototype built using HTML, CSS, JavaScript, and CSS. Features student grievance submission, auto-generated Ticket IDs, status tracking, admin dashboard, simulated email alerts, responsive UI, 7-day authority escalation, emergency priority detection, PDF receipt export, and an AI chatbot.

## Technologies used

- HTML5
- CSS3 (responsive layout and dark mode)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts: Plus Jakarta Sans
- Browser localStorage

## How to run

1. Download or copy the complete `samadhan` folder.
2. Open `index.html` in a modern web browser.
3. No installation, server, database, or backend is required for this frontend prototype.

## Features

- Student account creation and login with profile auto-fill
- Grievance submission and printable ticket receipt
- Simulated email acknowledgement
- Ticket status tracking and resolution timeline
- Working-day escalation assistance at 7 and 10 days
- Admin dashboard with ticket filters and status updates
- Active and resolved grievance views
- Light/dark mode and responsive mobile layout
- Local GBU logo asset and Font Awesome icons
